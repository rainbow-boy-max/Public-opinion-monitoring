## 成本优化建议（重要）

### 当前费用过高

按月 10,000 个视频计算，月费用约 **¥20,012**，其中：
- 视频 OCR：¥5,000
- 视频 ASR：¥15,000

### 优化方案

#### 1. 仅对重点视频进行 OCR/ASR（节省 70%）

设置优先级规则：
```typescript
const shouldProcessVideo = (video: ShortVideoEntity) => {
  return video.playCount > 100000 || 
         video.likeCount > 10000 ||
         video.commentCount > 1000;
};
```

预计节省：**¥14,000/月**

#### 2. 使用本地 Whisper 模型替代云 ASR（节省 100% ASR 费用）

部署方案：
- 服务器：GPU 服务器（RTX 3090）
- 模型：Whisper Large V3
- 成本：服务器租赁 ¥2,000/月

预计节省：**¥13,000/月**

#### 3. 智能抽帧算法（节省 50% OCR 费用）

仅在场景切换时抽帧，避免重复识别相同画面。

预计节省：**¥2,500/月**

### 优化后费用

| 方案 | 月费用 | 节省 |
|------|--------|------|
| 当前 | ¥20,012 | - |
| 优化方案 1 | ¥6,004 | 70% |
| 优化方案 1+2 | ¥3,004 | 85% |
| 优化方案 1+2+3 | ¥2,504 | 87.5% |

## 风险与应对

### 风险 1：第三方 API 限流

**风险描述**：抖音/快手 API 有频率限制（如 100次/分钟）

**应对措施**：
- 实现请求队列与限流控制
- 多账号轮询
- 缓存热门视频数据

### 风险 2：OCR/ASR 费用超预算

**风险描述**：大规模采集导致云服务费用过高

**应对措施**：
- 实施优先级规则（仅处理重点视频）
- 使用本地 Whisper 模型
- 设置月度预算告警

### 风险 3：视频 URL 失效

**风险描述**：抖音/快手视频链接有时效性

**应对措施**：
- 及时下载视频到 OSS
- 定期检查并更新失效链接
